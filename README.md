# Suhail Mobile Shop Raebareli - Premium Mobile Store

> **Font:** Rubik Sans Serif • **Backend:** 100% InsForge Only • **Auth:** Google OAuth + Email OTP • **Stack:** Next.js 14 + Vercel + InsForge + GitHub

**Shop:** Beside Canara Bank Building, In Front Of Chandapur Kothi, Kuchery Road, Rae Bareli - 229001, UP
**Instagram:** @suhail_mobile_shop_raebareli

## Features

### Customer Platform
- Homepage with hero slider (iPhone 16 Pro Max, S25 Ultra, OnePlus 13), brand marquee, trust bar, product grid
- Real products: Samsung S25 Ultra, iPhone 16 Pro Max, OnePlus 13, Vivo X200 Pro, Oppo Find X8 Pro, Realme GT 7 Pro
- Accessories: AirPods Pro 2, Buds 3 Pro, Watch 2R, Anker Charger
- Preorder Zone: S26 Ultra, iPhone 17 Pro Max, OnePlus 14 with bonus gifts
- Repair Service: Book repair, staff contact, genuine parts
- Search with history tracking
- Cart, Wishlist, My Account

### My Account
- Order History - from InsForge orders table
- Search History - what you searched (localStorage + InsForge)
- My Cart - saved items
- Wishlist
- Profile
- Admin Panel Inside My Account (Only for Admin) - No public admin button

### Admin Panel (Inside My Account Only for Admin)
- Single login for all (Google + Email OTP)
- Admin login: admin@suhailmobile.com / Suhail@123
- After login as admin, go to My Account → See red Admin Section with Dashboard, Products, Orders, Banners, Brands, Categories, Preorder, Accessories, Repair, Settings, Payments
